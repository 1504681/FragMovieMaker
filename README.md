# FragMovieMaker

Automatically combine gameplay clips and add music.

## How to Use

1. Upload video clips to the `videos` folder
2. Add your music to the `music` folder (name it `background.mp3`)
3. Go to the Actions tab in GitHub
4. Click "Run workflow"
5. Wait for processing to complete
6. Download your finished video from the Artifacts section

That's it!

## What It Does

- Puts your clips in order by creation date
- Combines them into one video
- Adds your background music
- Makes it available for download

## Tips

- Works with MP4 and MKV video files
- GitHub has a 100MB limit per file
- For larger files, use Git LFS (already set up)
